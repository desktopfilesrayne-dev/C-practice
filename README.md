# C Practice 💻

A collection of my C programming practice, exercises, and mini-projects as I learn the fundamentals of C.

## 🎯 Goal

The goal of this repository is to document my progress while learning C programming and to build a strong foundation through consistent practice.

I will gradually add programs as I learn new concepts and improve my programming skills.

## 📚 Topics

### Basics
Basic C programming concepts such as:

- Variables
- Data types
- Input and output
- `printf()`
- `scanf()`
- Arithmetic operators
- Expressions
- Typecasting
- Basic program structure

### If-Else
Decision-making and conditional statements:

- `if`
- `if-else`
- `else if`
- Nested `if`
- `switch`

### Loops
Repetition and iteration:

- `for`
- `while`
- `do-while`
- `break`
- `continue`

### Functions
Functions and modular programming:

- Creating functions
- Function parameters
- Return values
- Passing arguments
- Scope

### Mini-Projects
Small programs that combine multiple C programming concepts.
